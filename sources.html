Reproducibility

Four useful levels of reproducibility.

LevelMeaningExample
R1 · IntegrityReleased artifact can be hash-checked and consumed deterministically.ERA5-sensitive v2 hourly payload.
R2 · TransformationRetained inputs + code regenerate a derived artifact.Most historical/model transformations.
R3 · Source-to-resultAcquisition + transformation + model reproduce a result, subject to upstream access.Several source-bounded model chains.
R4 · Independent implementationSeparate implementations reproduce the same mathematical result.PyPSA/SciPy and PyPSA/OSeMOSYS common formulations.
Known gap: the original ERA5-sensitive v2 fitting script and raw ERA5 archive are not committed. The released chronology is integrity-verifiable, but the original fit is not fully source-to-fit reproducible from a fresh clone.
