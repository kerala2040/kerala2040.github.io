KSEBL topology and historical equipment evidence

Public grid maps/SLDs and a preserved 2022–23 PSS snapshot support the structural network screen. The PSS snapshot is historical and weaker than a current utility database.

CEA as independent external check

The current Kerala transmission plan reports 200+100 MVA at Shoranur, identifies the station as constrained and records further reinforcement. This strengthens hotspot geography while correcting the old 100 MVA whole-station interpretation.

Reproducibility levels

Reproducible is not binary.

LevelMeaningExamples
R1 · Integrity reproducibleReleased artifact can be hash-checked and consumed deterministically.ERA5-sensitive v2 hourly payload.
R2 · Transformation reproducibleRetained inputs + code regenerate derived output.Most historical, model and WP6 transformations.
R3 · Source-to-resultPublic acquisition + transformation + model reproduce result.Several source-bounded model chains, subject to upstream availability.
R4 · Independent implementationSeparate implementations reproduce same mathematical result.PyPSA/SciPy and PyPSA/OSeMOSYS common formulations.

Known open reproducibility gap

The original ERA5-sensitive v2 fitting script and raw ERA5 archive are not committed. The released chronology is integrity-verifiable; the original coefficient fit is not currently regenerable from a fresh clone.
