Source acceptance checks

  1. Document source institution, time zone, publication date, dataset licence and original field definitions.
  2. Record missing/duplicate intervals and official revisions before cleaning.
  3. Check only compatible accounting boundaries; reconcile aggregated interval energy to daily published values without silently normalising.
  4. Keep observed values separate from interpolation or reconstruction, with an explicit classification per record.
  5. Repeat prior model evaluations on independently observed periods before considering a new public operational conclusion.
