Methods

How the study was built.

Model complexity was limited by evidence, not software availability. A simpler model with visible assumptions was preferred to a sophisticated model populated with invented parameters.

Methodological philosophy

Progressive evidence ladder.

Start with the strongest observable quantity; preserve its accounting boundary; add only the simplest model required to answer the next question; test sensitivities; seek independent corroboration; fail closed when the evidence gate is not passed.

01

Acquire & audit

Official annual statistics, SLDC daily reports, CEA planning studies, KSEBL network material, ERA5 weather and project documents.

02

Classify evidence

Observed/source-reported, derived, proxy/screening and candidate-response evidence are not treated as interchangeable.

03

Reconstruct gaps

Only what is unobserved is modeled. Missing source dates remain explicitly missing in observational analyses.

04

Stress mechanisms

Demand, hydro timing, transfer capability, candidate resources and boundary injections are varied transparently.

05

Verify implementation

Conservation checks, unit tests, direct PyPSA runs, custom SciPy LP and OSeMOSYS comparisons.

06

Red-team conclusions

Source vintage, circular validation, leakage and claim wording are independently audited before presentation.

Hourly demand reconstruction

Known daily energy; modeled intraday shape.

Continuous measured Kerala hourly load was not available in the admitted public data. The model therefore conserves the strongest observed quantity—the daily MWh—and reconstructs only the 24-hour distribution.

For observed day d: Σₕ Load(d,h) = observed SLDC daily energy(d)

Features

  • Clock-time structure from sparse reported extrema.
  • Weekend structure.
  • ERA5 temperature / humidity-related terms and other weather descriptors.
  • Each day renormalized back to its known daily MWh.

Validation boundary

January–March reported extrema were withheld from fitting. The resulting error assesses intraday shape conditional on known daily energy. It is not a day-ahead load forecast.

Weather-sensitive RMSE: 155.2 MW vs sparse-static 162.0 MW.

Reproducibility limitation

The released v2 8,760-hour payload is cryptographically pinned and downstream use is reproducible, but the original coefficient-fitting script and raw ERA5 archive are not currently committed. The fit itself is therefore not source-to-fit reproducible from a fresh clone.

Chronological adequacy & expansion

8,760 hours before “optimal capacity”.

The statewide model asks whether available generation, storage and imports can meet each hour. Future demand scenarios are source-specific and are not averaged into a fictional consensus case.

Why full chronology?

Storage, evening peaks and renewable coincidence depend on sequence. Representative days can miss stressful runs unless carefully designed.

Why adequacy-first?

No Kerala-specific Value of Lost Load was admitted. A lexicographic objective first minimizes unserved energy, then minimizes partial investment/import cost among equally adequate solutions.

Stage 1: minimize Σ unserved_energyₜ
Stage 2: hold Stage-1 optimum, then minimize candidate investment + partial import cost

This is not a total-system welfare or least-cost model: existing fleet economics, unit commitment, forced outages, hourly landed import price and several system costs are absent.

Hydropower hierarchy

Timing bound → stateful pilot → physical-source gate.

v1.1

Same-day timing

Preserve each day's hydro MWh exactly; allow different hourly scheduling subject to power limits. Isolates the value of timing.

v1.2

Interday windows

Preserve hydro energy over 1/3/15/30-day windows to bracket how added temporal freedom changes adequacy.

v1.3+

Stateful Idukki

Add a storage state. v1.3 uses reconstructed net water balance; later gates require direct source-reported inflow/storage before physical claims.

v1.3 reconstructed forcing: Bₜ = Sₜ₊₁ − Sₜ + Gₜ / c
Replay: Sₜ₊₁ = Sₜ + Bₜ − Gₜ / c

Because B is constructed from the same storage change and generation, historical storage closure is algebraic. It verifies the state equation and alignment—not catchment hydrology.

Public network screen

Why linear screening instead of pretending to have an AC digital twin?

The public evidence supports topology and partial equipment ratings, but not measured bus-load chronology, unit dispatch, complete source impedances, reactive power or N-1 operating states.

Inputs

  • Source-backed 110-kV+ topology.
  • Conductor/current evidence where available.
  • PSS transformer-capacity evidence.
  • Bus load proxy from distribution-interface transformer MVA.
  • Eight extreme residual-import injection allocations.

Outputs

  • Candidate stressed corridors.
  • Robustness to boundary-injection location.
  • Independent comparison with CEA planning.

Not outputs: voltage stability, frequency stability, transient stability, N-1 security or operator loading.
